# Airish Fox Brand Base

Airish Fox использует мягкую fashion-палитру с ярким boutique-акцентом.

## Цвета

- Cat Mint: `#B8F2D0`
- Bitcoin Orange: `#F7931A`
- Milk: `#FFF7EA`
- Graphite: `#242424`
- Fox: `#D95F18`
- Soft Pink: `#FFB6C8`

## SVG assets

Brand SVG лежат в `static/images/brand/`:

- `fox-logo.svg` — основной логотип для navbar/footer.
- `fox-mark.svg` — компактный знак бренда.
- `fox-mascot-idle.svg` — статичный mascot для hero и будущих состояний.
- `fox-favicon.svg` — favicon.

Production-логотип Airish Fox — только собственный SVG. Emoji не используются как logo, favicon или mascot.
