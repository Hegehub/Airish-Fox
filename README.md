# Airish Fox

MVP сайта бренда одежды **airish-fox**: брендовая визитка + мини-витрина коллекции на Django.

## Что уже есть

- Django-проект `airish_fox` с чистой структурой `config/`, `apps/`, `templates/`, `static/`, `media/`.
- Приложения:
  - `core` — главная, страница о бренде, настройки сайта.
  - `catalog` — категории, товары, изображения товаров, коллекция и новинки.
  - `reviews` — отзывы клиентов.
  - `contacts` — форма заявки и сохранение обращений.
- Django Admin для всех моделей.
- Responsive UI на Django Templates + Tailwind CDN + кастомный CSS.
- Палитра Airish Fox: Cat Mint `#B8F2D0`, Bitcoin Orange `#F7931A`, Milk Background `#FFF7EA`, Graphite `#242424`, Fox Accent `#D95F18`, Soft Pink `#FFB6C8`.
- SQLite для локальной разработки и PostgreSQL-ready настройки через `DATABASE_URL`.

## Требования

- Python 3.12+
- pip
- SQLite локально; PostgreSQL можно подключить через переменную окружения `DATABASE_URL`.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Настройка окружения

Скопируйте пример переменных окружения:

```bash
cp .env.example .env
```

Для локального запуска можно оставить значения по умолчанию. Для PostgreSQL укажите, например:

```env
DATABASE_URL=postgresql://user:password@localhost:5432/airish_fox
```

## Миграции

```bash
python manage.py migrate
```

## Создание администратора

```bash
python manage.py createsuperuser
```

## Запуск dev server

```bash
python manage.py runserver
```

После запуска откройте:

- сайт: <http://127.0.0.1:8000/>
- админка: <http://127.0.0.1:8000/admin/>

## Как загрузить первые товары через admin

1. Войдите в `/admin/` под superuser.
2. В разделе **Настройки сайта** создайте запись с названием, слоганом, контактами и hero-изображением.
3. В разделе **Категории** добавьте категории: платья, костюмы, худи, аксессуары или любые другие капсулы.
4. В разделе **Товары** добавьте модели одежды:
   - выберите категорию;
   - заполните название, описание, цену, размеры, цвет;
   - загрузите главное изображение;
   - отметьте `Новинка`, если товар должен попасть на страницу новинок;
   - отметьте `Популярный`, если товар должен попасть в блок популярных товаров на главной.
5. При необходимости добавьте дополнительные изображения товара через inline-блок **Изображения товаров**.
6. В разделе **Отзывы** добавьте активные отзывы клиентов.
7. Заявки из формы будут появляться в разделе **Заявки**.

## Страницы

- `/` — главная страница.
- `/about/` — о бренде.
- `/collection/` — коллекция с фильтрацией по категории через query-параметр `?category=slug`.
- `/collection/new/` — новинки.
- `/reviews/` — отзывы.
- `/contacts/` — контакты и форма заявки.

## Примечания по MVP

В MVP намеренно нет корзины, онлайн-оплаты, личного кабинета, регистрации, SPA и блока пакетов услуг. Архитектура подготовлена для дальнейшего расширения: корзина, заказы, платежи, доставка, промокоды, поиск, избранное, REST API и интеграции с Telegram/WhatsApp.
